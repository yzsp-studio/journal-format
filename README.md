## 🇬🇧 English

Applies a journal, university, conference or course DOCX format to a paper manuscript by editing the OpenXML package directly rather than reconstructing the document, so body text, formulas, images, OLE objects, tables and relationships all stay in place. The format source can be a .docx template, explicit text rules, or formatting evidence extracted from a PDF, web page or image — but such weaker sources may only decide the Chinese/English single- or double-column layout, with remaining properties filled from a bundled fallback and the risk recorded in the final notes. A composite-request hard stop has the highest priority: if the same request mixes in writing, polishing, plagiarism reduction, translation, literature search or reference verification, it asks whether you want formatting only or a split task, and reads nothing or formats nothing before you answer.

### ✨ What it does

- Paper manuscript plus .docx template in → fully formatted DOCX out
- Edits OpenXML directly, leaving formulas, images, OLE objects, tables and relationships intact
- Accepts explicit text rules, or formatting evidence extracted from PDF, web page or image
- Weak sources may only set the layout; remaining properties come from fallback with risks noted
- Composite-request hard stop: mixed non-formatting demands force an A/B choice first
- Clear boundaries: no writing, polishing, plagiarism reduction, translation, ghostwriting or citations
